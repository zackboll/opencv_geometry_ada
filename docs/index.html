OpenCV Geometry Ada

A thick, idiomatic Ada 2022 binding for OpenCV's computational geometry: contour measurement and moments, convex hulls and defects, curve approximation, shape matching, fitting and enclosing shapes, convex and rotated-rectangle intersections, affine and perspective transforms, and Delaunay/Voronoi planar subdivisions. It reuses the shared value types of OpenCV Core Ada, such as OpenCV.Point_Array and OpenCV.Rotated_Rect. The public operations are in two packages: OpenCV.Geometry and OpenCV.Geometry.Subdiv2D.

Generated Ada API reference

The package specifications are the authoritative API declarations. This reference is generated from the main branch and can describe operations newer than the latest Alire release. The repository README describes the OpenCV versions exercised by CI and the per-feature compatibility notes.

Image-processing operations such as contour extraction from images, filtering and warping belong to OpenCV Imgproc Ada, not to this binding. On OpenCV 4 the native geometry functions live in OpenCV's imgproc library and on OpenCV 5 in its geometry library; the Ada packages are the same on both.

Build from source

Install the native OpenCV development library, pkg-config and a C++17 compiler, then build with Alire, which resolves opencv_core from the Alire index within the manifest's supported range:

git clone https://github.com/zackboll/opencv_geometry_ada.git geometry
cd geometry
alr -n build

Basic usage

with OpenCV;
with OpenCV.Geometry;

procedure Example is
   use type OpenCV.Float64_Value;
   Rectangle : constant OpenCV.Geometry.Contour :=
     [(X => 0, Y => 0), (X => 4, Y => 0), (X => 4, Y => 3), (X => 0, Y => 3)];
   Perimeter : constant OpenCV.Float64_Value :=
     OpenCV.Geometry.Arc_Length (Rectangle, Closed => True);
   Hull      : constant OpenCV.Geometry.Contour :=
     OpenCV.Geometry.Convex_Hull (Rectangle);
begin
   pragma Assert (OpenCV.Geometry.Contour_Area (Rectangle) = 12.0);
   pragma Assert (Perimeter = 14.0);
   pragma Assert (OpenCV.Geometry.Is_Convex (Rectangle));
   pragma Assert (Hull'Length = 4);
end Example;

A Contour is an Ada-owned array of integer points. Convex_Hull returns a new Ada-owned contour of hull points, and Rectangle is not modified by any of these calls.
